# MZ TGM — Divoom Times Gate PC Monitor tray app

This app pushes hardware stats from your PC to a display on your Divoom Times Gate.

![Screenshot](https://raw.githubusercontent.com/Mizstik/mizstik.github.io/refs/heads/master/mz-tgm2-screenshot1.png)

The app can be configured to automatically start on boot, start minimized, and also automatically activate the PC Monitor on the Times Gate on launch.
