Preset ID (0 = auto-detect)

To prevent the Times Gate from resetting all other displays when activating the monitoring widget, it needs to know the ID of the preset that's being used. When this is set to 0, the app will query Divoom cloud for the last known preset ID. If you know what this ID is and you never change it, enter it in the box and the app will use it without contacting the cloud API.
